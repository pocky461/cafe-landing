# ☕ 모닝브루 카페 랜딩 페이지

가상의 동네 카페 "모닝브루"를 소개하는 간단한 한 페이지짜리 랜딩 페이지입니다. AI 에이전트 수업 실습용으로 만들었습니다.

## 구성

| 파일 | 설명 |
|------|------|
| `index.html` | 페이지 본문 (히어로, 대표 메뉴, 카페 소개, 오시는 길) |
| `style.css` | 스타일 및 모바일 반응형 레이아웃 |

## 실행 방법

별도 설치 없이 `index.html`을 브라우저에서 열면 됩니다.

## 특징

- 순수 HTML/CSS (JavaScript, 빌드 도구 없음)
- 모바일 화면 대응 반응형 디자인
- 메뉴·소개·오시는 길로 이동하는 부드러운 스크롤 네비게이션
